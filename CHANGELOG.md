# Changelog

## v0.0.2

- Added short sound cues when cycling and confirming conversation choices.
- Lower-left command icons now invert while held; dragging outside cancels the click.
- Updated the application's About and Finder version resources.
- Rebuilt save-free 1.44 MB HFS installation disks for the Color and Monochrome editions.

## v0.0.1

Initial Macintosh release, available in **Monochrome** and **Color** editions.

- Native 68K application with a 512 × 342 screen layout.
- City exploration, conversations, databases, quests, and the implemented route through the ending.
- Automatic NPC arrival dialogue and speech bubbles.
- Perspective cyberspace navigation with a 2D map toggle.
- ICE and AI combat with dedicated action controls.
- Standard Mac file menus, text saves, controls help, and About.
- Edition-specific Finder icons, including a separately drawn monochrome icon.
- App-only 1.44 MB HFS images, without save files, system software or ROMs.
